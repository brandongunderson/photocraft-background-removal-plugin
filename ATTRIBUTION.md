# Source and asset attribution

This project keeps processing dependencies and model assets separate from the PhotoCraft host.
The source and asset revisions/checksums used for this build are recorded in
`vendor/rust-background-removal/UPSTREAM.json` and `runtime/downloads.json`.

| Path | Work and source | Author | Upstream license declaration |
|---|---|---|---|

| `runtime/models/isnet.onnx`, `isnet_fp16.onnx` | [IMG.LY ISNet ONNX models](https://huggingface.co/imgly/isnet-general-onnx/tree/440dea96dd4a3b06bbbf5abec3e26569dd7ec49f) | Model authors identified by IMG.LY; underlying DIS research by Xuebin Qin and collaborators | IMG.LY model card declares MIT; copied card and third-party declarations in `runtime/licenses/` |
| `runtime/models/isnet_quint8.onnx` | [IMG.LY quantized ISNet model](https://github.com/imgly/background-removal-js/tree/12f56cc4f2a90d624e165a715748d22efc7a1d93/bundle/models) | Model authors identified by IMG.LY | IMG.LY's third-party file declares ISNET models MIT; the JavaScript application is not included |
